# Web Interface (next milestone)

Planned pages:

- **Certificate lookup:** enter a certificate ID and see its full history (issued, transferred, retired)
- **Producer dashboard:** submit readings and view pending energy and certificates
- **Buyer dashboard:** view owned certificates, transfer, and retire
- **Regulator panel:** register members, suspend producers, review flagged readings

Planned tools: HTML/JavaScript with Ethers.js, connected to MetaMask.
