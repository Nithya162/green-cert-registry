# Tests (next milestone)

Planned test cases:

- Only the regulator can register, suspend, or reinstate members
- A suspended producer cannot submit readings
- The same data hash cannot be submitted twice
- Only the Data Checker can approve or flag readings
- Certificates are issued per full 1 MWh, with the remainder carried forward
- Only the owner can transfer or retire a certificate
- Certificates can only be transferred to registered buyers
- A retired certificate cannot be transferred or retired again
